# TravelFlow Demo Platform

Демонстрационная туристическая платформа TravelFlow: адаптивный сайт и Telegram-бот работают как единый сервис, используют общий каталог и сохраняют заявки в одну базу.

## Возможности

- каталог и карточки экскурсий;
- пошаговый подбор по аудитории, интересам и формату отдыха;
- бронирование с выбором даты и количества гостей;
- передача новой заявки менеджеру;
- сохранение заявок в SQLite;
- админ-панель `/admin`: поиск, фильтры, статусы и статистика;
- редактирование карточек и фотографий экскурсий из Telegram.
- адаптивный сайт с каталогом, подробными карточками и онлайн-заявкой;
- единые цены, фотографии и доступность экскурсий на сайте и в боте;
- уведомление менеджера о заявках с сайта в Telegram.

## Локальный запуск

Требуется Python 3.11–3.13.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Заполните `.env`, затем запустите:

```powershell
python main.py
```

Переменные окружения:

- `BOT_TOKEN` — токен Telegram-бота от BotFather;
- `MANAGER_CHAT_ID` — чат, куда отправляются новые заявки и сообщения;
- `ADMIN_USER_IDS` — Telegram ID администраторов через запятую;
- `LOG_LEVEL` — уровень журналирования, по умолчанию `INFO`.
- `PORT` — HTTP-порт сайта; Railway задаёт его автоматически.

После запуска доступны:

- сайт: `http://localhost:8000`;
- проверка состояния: `http://localhost:8000/health`;
- Telegram-бот: long polling в том же процессе.

## Docker

```powershell
docker build -t travelflow-bot .
docker run --env-file .env -v travelflow-data:/app/data travelflow-bot
```

Том `/app/data` обязателен: без него заявки, изменения карточек и загруженные фотографии будут потеряны при пересоздании контейнера.

## Railway

1. Создайте проект из репозитория.
2. Railway автоматически прочитает `railway.toml` из корня репозитория.
3. Добавьте переменные из `.env.example`.
4. Подключите постоянный Volume с точкой монтирования `/app/data`.
5. Создайте публичный домен для сайта в настройках сервиса.
6. Разверните сервис и проверьте сайт, `/start`, создание заявки и `/admin`.

## Ограничения демо

- SQLite подходит для одного экземпляра бота; перед горизонтальным масштабированием нужна PostgreSQL.
- Контент с пометкой `TODO` не показывается пользователю и отображается как «Уточняется у менеджера».
- Платёжный сценарий пока демонстрационный и не списывает деньги.
